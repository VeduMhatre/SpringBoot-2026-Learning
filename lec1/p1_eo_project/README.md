\# Even Odd Checker Web Application



A lightweight full-stack Java application built using Spring Boot and plain HTML/JavaScript to evaluate whether a user-provided integer is even or odd.



\---



💡 Key Fundamentals Covered

@RestController`\*\*: Exposes the Java application as a RESTful web service returning raw response data directly to the client.


@CrossOrigin`\*\*: Enables Cross-Origin Resource Sharing (CORS) to accept requests from web browsers on different ports/domains.


HTTP GET Protocol (`@GetMapping`)\*\*: Configures endpoint routing for data retrieval operations over HTTP GET.

@RequestParam`\*\*: Binds URL query string parameters directly into Java method arguments.


Client-Side Fetch API\*\*: Connects the HTML frontend dynamically to the Spring Boot REST API using asynchronous HTTP requests.



\---



🛠️ Prerequisites

Java Development Kit (JDK):\*\* Version 17 or higher

Apache Maven:\*\* Installed globally or accessible via the Maven Wrapper (`mvnw`)

Web Browser:\*\* Any modern browser (Chrome, Firefox, Edge, Safari)
